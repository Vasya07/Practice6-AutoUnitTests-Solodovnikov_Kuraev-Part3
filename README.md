## Функциональность

### Модуль авторизации
- Проверка логина и пароля
- Обработка пустых полей
- Подсчет неудачных попыток
- Отображение CAPTCHA после 3 неудачных попыток
- Визуальный шум CAPTCHA (линии, точки, эллипсы, искажение букв)

### Модуль регистрации
- Валидация логина (только буквы, цифры, _)
- Проверка длины пароля (мин. 4 символа)
- Подтверждение пароля
- Проверка уникальности логина

## Бонусное задание: CAPTCHA с шумом

Реализована CAPTCHA, которая:
- Появляется после 3 неудачных попыток входа
- Генерирует случайный 5-значный код (цифры + заглавные буквы, исключая похожие символы)
- Добавляет визуальный шум: случайные линии, точки, эллипсы
- Искажает каждую букву отдельно (разный размер, цвет, положение)
- Обновляется по кнопке или клику на картинку
- Проверяет введенный код перед повторной попыткой

**Количество автоматизированных тестов для CAPTCHA:** 9

## Возможные ошибки и их обработка

| Ситуация | Обработка |
|----------|-----------|
| Пустой логин/пароль | Сообщение: "Логин/пароль не может быть пустым" |
| Неверный логин/пароль | Отказ в доступе, увеличение счетчика попыток |
| 3 неудачные попытки | Активация CAPTCHA |
| Неверный код CAPTCHA | Сообщение об ошибке, обновление CAPTCHA |
| Пароль короче 4 символов | Сообщение: "Пароль должен содержать минимум 4 символа" |
| Несовпадение паролей | Сообщение: "Пароли не совпадают" |
| Недопустимые символы в логине | Сообщение о допустимых символах (буквы, цифры, _) |
